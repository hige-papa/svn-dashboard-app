## 1. はじめに

### 1.1 Tascalとは

Tascal（タスカル）は、社員のタスク管理・カレンダースケジューリングを一元的に行う社内Webアプリケーションです。以下の機能を統合的に提供します。

| 機能 | 概要 |
|------|------|
| カレンダー管理 | 予定の登録・閲覧（日別/週別/月別ビュー） |
| 勤怠管理 | 出社/リモート/外出/休暇の登録、ランチ・夕食参加状況 |
| Wiki | 社内ナレッジの作成・共有 |
| ランチシャッフル | 参加者のランダムチーム分け |
| マスター管理 | ユーザー・施設・設備・チーム・部署の管理 |
| プロフィール | 自分の情報の管理 |

### 1.2 対応環境

| 項目 | 内容 |
|------|------|
| 対応ブラウザ | Chrome / Firefox / Safari / Edge（最新バージョン） |
| 対応デバイス | PC（Webブラウザ） |
| UI言語 | 日本語 |
| タイムゾーン | Asia/Tokyo（日本標準時） |

### 1.3 ユーザー権限

Tascalには3つの権限レベルがあります。

| 権限 | 説明 | 主な操作範囲 |
|------|------|-------------|
| **admin** | 管理者 | 全機能へのアクセス。ユーザー・施設・設備の登録/編集/削除、祝日管理、設定変更 |
| **user** | 一般ユーザー | カレンダー操作、勤怠登録、Wiki記事の作成/編集、プロフィール編集 |
| **viewer** | 閲覧者 | カレンダー・各種データの閲覧のみ |

## 2. ログイン・認証

### 2.1 ログイン方法

1. ブラウザでTascalのURLにアクセスします
2. サインイン画面が表示されます
3. 管理者から発行された **メールアドレス** と **パスワード** を入力します
4. 「ログイン」ボタンをクリックします
5. ログイン成功後、ダッシュボードに遷移します

**補足:**
- Enterキーでもフォーム送信が可能です
- ログイン中はボタンにローディングインジケータが表示されます

### 2.2 パスワードを忘れた場合

1. サインイン画面の「パスワードを忘れた方はこちら」リンクをクリックします
2. パスワードリセット画面（`/auth/password/reset`）が表示されます
3. 登録済みのメールアドレスを入力し「送信」ボタンをクリックします
4. メールに届いたリンクからパスワードを再設定してください

### 2.3 メールアドレスの変更

1. ログイン後、メールアドレス変更画面（`/auth/email/reset`）にアクセスします
2. 新しいメールアドレスを入力し「変更」ボタンをクリックします
3. 新しいメールアドレス宛に確認メールが送信されます
4. 確認メールのリンクをクリックして変更を完了してください

### 2.4 ログアウト

1. サイドバー下部の「ログアウト」をクリックします
2. サインイン画面にリダイレクトされます

### 2.5 アカウントが無効化された場合

管理者によりアカウントが **inactive**（無効）に設定された場合、自動的にログアウトされます。管理者に連絡してアカウントの再有効化を依頼してください。

## 3. カレンダー機能

### 3.1 カレンダーの基本画面

カレンダー画面（`/calendar`）には以下の3つのビューがあります。

| ビュー | 表示範囲 | 表示対象 | 用途 |
|--------|---------|---------|------|
| **日次（日別）** | 1日 | ログインユーザーの予定のみ | 自分の1日の予定を詳しく確認 |
| **週次（週別）** | 1週間（月〜日） | **全ユーザー**の予定 | チーム全体のスケジュール確認 |
| **月次（月別）** | 1ヶ月（6週分） | ログインユーザーの予定のみ | 自分の月間スケジュール概観 |

### 3.2 ビューの切り替え

カレンダーヘッダーの **[日次][週次][月次]** ボタンで切り替えます。選択したビューはブラウザに保存され、次回アクセス時に復元されます。

### 3.3 日付の移動

| 操作 | 説明 |
|------|------|
| **[◀]** ボタン | 前の日/週/月へ移動 |
| **[▶]** ボタン | 次の日/週/月へ移動 |
| **[今日]** ボタン | 本日の日付に移動 |
| **日付ピッカー** | 任意の日付に直接ジャンプ |

### 3.4 週次ビューの使い方

週次ビューでは全ユーザーの予定が横型タイムラインで表示されます。

- **ユーザーフィルター**: 表示するユーザーを選択/非選択で切り替えられます
- **イベントカード**: 時間帯に応じた横棒で表示されます
- **イベントカードのクリック**: 予定の詳細パネルが表示されます

### 3.5 イベントの種別と色

| 種別 | 表示名 | 色 |
|------|--------|---|
| meeting | ミーティング | 青系 |
| focus | 集中作業 | 緑系 |
| away | 外出 | オレンジ系 |
| vacation | 休暇 | 赤系 |
| normal | 通常 | グレー系 |
| other | その他 | 紫系 |

### 3.6 祝日の表示

管理者が登録した会社祝日はカレンダー上に表示されます。祝日の登録・管理は管理者のみ可能です。

### 3.7 プライベートイベント

プライベートに設定されたイベントは、**参加者以外**には「予定あり」とだけ表示され、タイトルや詳細は見えません。

## 4. 予定の登録・編集・削除

### 4.1 予定の新規登録

1. カレンダー画面の **「予定を登録」** ボタンをクリックします
2. 予定登録画面（`/calendar/register`）が表示されます
3. 以下の項目を入力します

| 項目 | 必須 | 説明 |
|------|------|------|
| タイトル | ○ | 予定のタイトル |
| イベント種別 | ○ | ミーティング/集中作業/外出/休暇/通常/その他 |
| 日付種別 | ○ | 単日/範囲指定/繰り返し |
| 日付 | ○ | 種別に応じた日付 |
| 開始時刻 | ○ | 開始時刻（HH:mm） |
| 終了時刻 | ○ | 終了時刻（HH:mm）※開始時刻より後 |
| 参加者 | × | ユーザーを複数選択 |
| 施設 | × | 会議室などの施設を選択 |
| 設備 | × | プロジェクターなどの設備を選択 |
| 説明 | × | 詳細な説明 |
| プライベート | × | ONにすると参加者以外に非公開 |

4. **「予定を登録」** ボタンをクリックします

### 4.2 日付種別の詳細

#### 単日予定
指定した1日の予定です。

#### 範囲指定予定
開始日〜終了日の期間にわたる予定です。期間内の各日に予定が作成されます。

#### 繰り返し予定

繰り返しパターンを選択できます。

| パターン | 説明 |
|---------|------|
| 毎日 | 毎日繰り返し |
| 平日 | 月〜金のみ繰り返し |
| 毎週 | 指定した曜日に繰り返し（曜日を選択） |
| 毎月 | 毎月同日、または毎月第N曜日に繰り返し |
| 毎年 | 毎年同月同日に繰り返し |

繰り返しの終了条件も設定できます。

| 終了条件 | 説明 |
|---------|------|
| 終了なし | 1年分の予定を自動生成 |
| 日付指定 | 指定日まで繰り返し |
| 回数指定 | 指定回数分繰り返し |

### 4.3 コンフリクト（重複）の検出

予定登録時に以下のコンフリクトが自動検出されます。

- **参加者の時間重複**: 同じ参加者が同時間帯に別の予定がある場合
- **施設の時間重複**: 同じ施設が同時間帯に別の予定で使用中の場合
- **設備の時間重複**: 同じ設備が同時間帯に別の予定で使用中の場合

コンフリクトが検出された場合、警告メッセージが表示されます。**警告が表示されても登録は可能です**が、重複を確認のうえ登録してください。

### 4.4 予定の編集

1. カレンダー上のイベントカードをクリックします
2. 予定詳細パネルが表示されます
3. **「編集」** ボタンをクリックします
4. 予定編集画面（`/calendar/[id]/edit`）で内容を変更します
5. **「予定を更新」** ボタンをクリックします

### 4.5 予定の削除

1. 予定詳細パネルで **「削除」** ボタンをクリックします
2. 削除確認ダイアログが表示されます

**単日予定** の場合はそのまま削除されます。

**範囲指定予定・繰り返し予定** の場合は削除オプションを選択できます。

| オプション | 説明 |
|-----------|------|
| この予定のみ | 選択した1件だけ削除 |
| すべての予定 | 同一グループの全予定を削除 |
| これ以降の予定 | 選択日以降の予定を削除 |
| これ以前の予定 | 選択日以前の予定を削除 |

### 4.6 カレンダー位置の保持

予定の登録・編集画面から戻った際、**操作前に表示していた週/月の位置が自動的に復元**されます。ブラウザのlocalStorageに保存されるため、ブラウザを閉じるまで有効です。

## 5. 勤怠管理（日別オプション）

### 5.1 概要

勤怠管理画面（`/attendance`）では、日別の勤務形態やランチ・夕食の参加状況を登録できます。

### 5.2 登録できる項目

#### 勤務形態

| 値 | 表示名 | 説明 |
|---|--------|------|
| office | 出社 | オフィス勤務 |
| remote | リモート | 在宅勤務 |
| out | 外出 | 社外活動 |
| vacation | 休暇 | 休暇取得 |
| pending | 未定 | 未決定 |

#### ランチ参加・夕食参加

| 値 | 表示名 |
|---|--------|
| possible | 参加 |
| impossible | 不参加 |
| pending | 未定 |

### 5.3 操作方法

1. 勤怠管理画面で日付範囲を選択します
2. 対象日の各項目を選択・変更します
3. 変更は自動的に保存されます

## 6. Wiki（ナレッジベース）

### 6.1 概要

Wiki機能（`/wiki`）では社内のナレッジを作成・共有できます。Markdown形式で記事を作成でき、カテゴリやタグで整理できます。

### 6.2 記事の閲覧

- **Wikiトップ**: 記事一覧と人気記事が表示されます
- **検索**: ヒーローセクションの検索ボックスで記事を検索できます
- **タグ絞り込み**: タグチップをクリックして関連記事を絞り込めます
- **カテゴリ別**: カテゴリ別ページで分類された記事を閲覧できます

### 6.3 記事の作成

1. Wikiトップの **「新しい記事を作成」** ボタンをクリックします
2. 記事作成画面（`/wiki/new`）が表示されます
3. 以下の項目を入力します

| 項目 | 必須 | 説明 |
|------|------|------|
| タイトル | ○ | 記事のタイトル |
| カテゴリ | ○ | 記事のカテゴリ |
| タグ | × | 記事のタグ（複数選択可） |
| 本文 | ○ | Markdown形式で記事本文を入力 |
| ステータス | ○ | published（公開）/ draft（下書き）/ archived（アーカイブ） |

4. **「保存」** ボタンをクリックします

### 6.4 Markdownエディタ

記事本文の入力にはMarkdownエディタ（EasyMDE）を使用します。

- **ツールバー**: 見出し、太字、斜体、リンク、画像、リスト等のボタンがあります
- **リアルタイムプレビュー**: 入力中に右側にプレビューが表示されます
- **全画面編集**: 全画面で集中して編集できます

### 6.5 バージョン管理

記事を更新すると自動的にバージョン番号がインクリメントされ、更新前のスナップショットが履歴として保存されます。

## 7. ランチシャッフル

### 7.1 概要

ランチシャッフル（`/lunch`）は、参加者をランダムにチーム分けする機能です。リアルタイムで結果が全ユーザーに共有されます。

### 7.2 使い方

1. 参加者リスト（最大20名）に参加者名を入力します
2. **「シャッフル実行」** ボタンをクリックします
3. Fisher-Yatesアルゴリズムでランダムに並べ替えられ、3〜4人ずつのチームに自動分割されます
4. 結果がFirestoreに保存され、全ユーザーにリアルタイム共有されます

### 7.3 結果の確認

シャッフル結果の下に、最終実行日時と実行者が表示されます。

## 8. マスター管理（施設・設備・チーム・部署）

### 8.1 共通操作

施設・設備・チーム・部署の管理画面は共通のパターンで構成されています。

| 操作 | 画面 | 権限 |
|------|------|------|
| 一覧表示 | `/{resource}` | 全ユーザー |
| 新規登録 | `/{resource}/new` | **adminのみ** |
| 詳細表示 | `/{resource}/[id]` | 全ユーザー |
| 編集 | `/{resource}/[id]/edit` | **adminのみ** |

### 8.2 一覧画面の機能

- **検索ボックス**: 名前やコードで絞り込み
- **フィルター**: カテゴリやステータスで絞り込み
- **統計カード**: 総数・利用可能数・カテゴリ数を表示
- **表示切替**: グリッド（カード形式）とリスト（テーブル形式）を切り替え
- **ページネーション**: 前へ/次へボタンでページ移動

### 8.3 ステータスの意味

| ステータス | 説明 |
|-----------|------|
| available | 利用可能 |
| in_use | 使用中 |
| maintenance | メンテナンス中 |

## 9. プロフィール管理

1. プロフィール画面の **「編集」** ボタンをクリックします

| 項目 | 編集可否 | 備考 |
|------|---------|------|
| 名前 | ○ | |
| メールアドレス | × | 別画面で変更 |
| 電話番号 | ○ | |

| 部署 | ○ | |

## 10. トラブルシューティング

### 10.1 ログインできない

| 状況 | 対処方法 |
|------|---------|
| 「ユーザーが見つかりません」と表示される | メールアドレスが正しいか確認してください |
| 「パスワードが間違っています」と表示される | パスワードを確認してください。解決しない場合はパスワードリセットを実施 |
| 「このメールアドレスは既に使用されています」 | 別のメールアドレスを使用してください |
| ログイン後すぐにログアウトされる | アカウントが無効化されています。管理者に連絡してください |

### 10.2 カレンダーが表示されない / 遅い

| 状況 | 対処方法 |
|------|---------|
| データが表示されない | ブラウザをリロードしてください |
| 表示が遅い | 初回読み込みは最大3秒程度かかります。2回目以降はキャッシュにより高速化されます |
| 古いデータが表示される | キャッシュの有効期限（マスターデータ: 10時間）を過ぎれば自動更新されます。急ぎの場合はブラウザをリロードしてください |

### 10.3 予定が登録できない

| 状況 | 対処方法 |
|------|---------|
| 「タイトルは必須です」と表示される | タイトルを入力してください |
| 「開始時刻は終了時刻より前にしてください」 | 開始時刻と終了時刻を確認してください |
| 「曜日を選択してください」 | 繰り返し（毎週）の場合、曜日を1つ以上選択してください |
| コンフリクト警告が表示される | 参加者・施設・設備の時間重複です。確認のうえ登録してください |

### 10.4 他のユーザーの予定が見えない

- **月次・日次ビュー** ではログインユーザーの予定のみ表示されます。全員の予定を確認するには **週次ビュー** に切り替えてください
- **プライベートイベント** は参加者以外には「予定あり」とだけ表示されます。これは正常な動作です

### 10.5 画面表示の問題

| 状況 | 対処方法 |
|------|---------|
| レイアウトが崩れる | ブラウザのキャッシュをクリアしてリロードしてください |
| サイドバーが消えた | ヘッダー左端のハンバーガーメニュー（≡）をクリックしてください |
| モバイル表示で操作しづらい | PCのWebブラウザでの利用を推奨しています |

### 10.6 その他

| 状況 | 対処方法 |
|------|---------|
| メニューが一部表示されない | 権限によってメニューが制限されています。必要な場合は管理者に連絡してください |
| データが更新されない | ブラウザのリロード、またはキャッシュクリアを試してください |
| エラーメッセージが表示される | エラー内容をメモし、システム管理者に報告してください |

## 付録B: データのキャッシュについて

Tascalではパフォーマンス向上のため、以下のデータをキャッシュしています。

| キャッシュ対象 | 有効期間 | 自動更新タイミング |
|-------------|---------|-----------------|
| ユーザー情報 | 10時間 | アプリ起動時 |
| 祝日情報 | 10時間 | アプリ起動時 |
| 施設情報 | 10時間 | アプリ起動時 |
| 設備情報 | 10時間 | アプリ起動時 |
| 日別オプション | 1時間 | 画面表示時 |
| カレンダー表示位置 | ブラウザを閉じるまで | ビュー変更時 |

最新データを確認したい場合は、ブラウザのページリロードを行ってください。

## 付録C: サポート窓口

| 問い合わせ内容 | 連絡先 |
